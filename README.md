# Разница между `&T` и `&mut T` в Rust

## Краткий ответ

| | `&T` | `&mut T` |
|---|---|---|
| **Название** | **Shared reference** (разделяемая ссылка) | **Exclusive reference** (эксклюзивная ссылка) |
| **Одновременно** | **Много** | **Одна** |
| **Чтение** | ✅ Да | ✅ Да |
| **Запись** | ❌ Нет | ✅ Да |
| **Копируемость** | `Copy` | **Не** `Copy` |
| **Правило** | Сколько угодно | **Эксклюзивно** |

**Ключевое:** `&T` и `&mut T` — это **разные категории типов**, а **не** «модификатор изменяемости».

## `&T` — Shared reference

### Что это

```rust
let v = vec![1, 2, 3];
let r = &v;   // ← shared reference
```

- **Разделяемая** ссылка.
- **Много** одновременно.
- **Только чтение**.
- **`Copy`** — копируется как указатель.

### Пример

```rust
let v = vec![1, 2, 3];

let r1 = &v;
let r2 = &v;
let r3 = &v;

println!("{:?} {:?} {:?}", r1, r2, r3);   // ✅
```

**Сколько угодно** `&T` одновременно.

## `&mut T` — Exclusive reference

### Что это

```rust
let mut v = vec![1, 2, 3];
let r = &mut v;   // ← exclusive reference
```

- **Эксклюзивная** ссылка.
- **Только одна** одновременно.
- **Чтение и запись**.
- **Не `Copy`**.

### Пример

```rust
let mut v = vec![1, 2, 3];

let r = &mut v;
r.push(4);
println!("{:?}", r);   // ✅

// let r2 = &mut v;   // ❌ нельзя — r ещё жив
```

**Только одна** `&mut T` одновременно.

## Правило XOR (исключающего ИЛИ)

**В каждой точке программы:**

> **Либо** одна `&mut T`, **либо** сколько угодно `&T`.

### Таблица истинности

```
&mut T   &T
------   ---
  0  XOR  0  =  0   ✅ (ничего)
  0  XOR  1  =  1   ✅ (только &T)
  1  XOR  0  =  1   ✅ (только &mut T)
  1  XOR  1  =  0   ❌ (&mut + &T)
```

**Одновременно** `&mut T` **и** `&T` — **запрещено**.

## Разбор примера

```rust
let mut v = vec![1, 2, 3, 4, 5];

let r1 = &v;   // shared
let r2 = &v;   // shared
println!("{:?} {:?}", r1, r2);   // ✅ много shared

// r1 и r2 больше не используются — NLL
let r3 = &mut v;   // ✅ теперь можно
r3.push(6);
println!("{:?}", r3);   // [1, 2, 3, 4, 5, 6]
```

### Что происходит

1. **`r1`, `r2`** — **две** `&T` **одновременно**.
2. **`println!`** — **последнее** использование `r1`, `r2`.
3. **NLL** (Non-Lexical Lifetimes) — **borrow checker** понимает, что `r1`, `r2` **больше не нужны**.
4. **`r3 = &mut v`** — **можно** создать `&mut`, потому что `r1`, `r2` **мертвы**.

## NLL (Non-Lexical Lifetimes)

**NLL** — **область** жизни заимствования определяется **использованием**, а **не** лексическими **скобками**.

### До NLL (Rust 2015)

```rust
let mut v = vec![1, 2, 3];
let r1 = &v;
let r2 = &v;
println!("{:?} {:?}", r1, r2);
// r1, r2 живы до конца блока → r3 нельзя
let r3 = &mut v;   // ❌ ошибка
```

**Borrow** жил **до конца** `{}`.

### После NLL (Rust 2018+)

```rust
let mut v = vec![1, 2, 3];
let r1 = &v;
let r2 = &v;
println!("{:?} {:?}", r1, r2);
// r1, r2 больше не используются → мертвы
let r3 = &mut v;   // ✅ можно
```

**Borrow** живёт **до последнего** использования.

## Что **запрещено**

### 1. Две `&mut`

```rust
let mut v = vec![1, 2, 3];

let r1 = &mut v;
let r2 = &mut v;   // ❌ ошибка
```

**Ошибка:**

```
error[E0499]: cannot borrow `v` as mutable more than once at a time
```

### 2. `&mut` + `&`

```rust
let mut v = vec![1, 2, 3];

let r1 = &v;
let r2 = &mut v;   // ❌ ошибка
```

**Ошибка:**

```
error[E0502]: cannot borrow `v` as mutable because it is also borrowed as immutable
```

### 3. Использование после move

```rust
let mut v = vec![1, 2, 3];
let r = &mut v;

println!("{:?}", v);   // ❌ пока r жив
```

## Зачем это правило

### 1. **No data race**

**Гарантия:** нет **гонок данных** — либо **много читателей**, либо **один писатель**.

### 2. **Noalias-оптимизация**

**Компилятор** знает:

- `&T` — **никто не пишет** → можно **кэшировать**.
- `&mut T` — **никто не читает** → можно **оптимизировать**.

### 3. **Итераторы**

```rust
let mut v = vec![1, 2, 3];
for x in &mut v {   // &mut
    *x += 1;
}

for x in &v {   // & (после)
    println!("{}", x);
}
```

## Схема

```
&mut T:
[данные] ← одна ссылка (эксклюзивно)

&T:
[данные] ← много ссылок (разделяемо)

&mut + &T:
[данные] ← ❌ запрещено
```

## Сводная таблица

| Операция | `&T` | `&mut T` |
|---|---|---|
| **Чтение** | ✅ | ✅ |
| **Запись** | ❌ | ✅ |
| **Количество** | **Много** | **Одна** |
| **`Copy`** | ✅ | ❌ |
| **`Sync`** | ✅ | ❌ |
| **`Send`** | ✅ | ✅ |

## Сводная таблица правил

| Ситуация | Разрешено? |
|---|---|
| **Много `&T`** | ✅ |
| **Одна `&mut T`** | ✅ |
| **`&T` + `&mut T`** | ❌ |
| **Две `&mut T`** | ❌ |
| **`&T` после `&mut T`** | ✅ (если `&mut` мёртв) |

## Практический пример: swap

```rust
fn swap(a: &mut i32, b: &mut i32) {
    let tmp = *a;
    *a = *b;
    *b = tmp;
}

let mut x = 1;
let mut y = 2;

swap(&mut x, &mut y);   // ✅ две &mut на разные переменные
```

**Правило:** `&mut` на **разные** значения — **можно**.

## Сводная таблица

| Аспект | `&T` | `&mut T` |
|---|---|---|
| **Название** | Shared | Exclusive |
| **Алиасинг** | Много | Один |
| **Изменение** | ❌ | ✅ |
| **Инвариант** | XOR | XOR |
| **NLL** | ✅ | ✅ |

## Итог

- **`&T`** — **shared** reference: **много**, **только чтение**, **`Copy`**.
- **`&mut T`** — **exclusive** reference: **одна**, **чтение и запись**, **не `Copy`**.
- **Правило XOR:** либо **одна `&mut T`**, либо **много `&T`**.
- **NLL** — borrow живёт **до последнего** использования, а **не** до конца блока.
- **Зачем:** no data race, noalias-оптимизация.
- **В вашем примере:**
  - `r1`, `r2` — shared;
  - после `println!` они **мертвы** (NLL);
  - `r3 = &mut v` — **можно**.
- **Правило:** `&T` — **читать**; `&mut T` — **изменять**; **не одновременно**.
